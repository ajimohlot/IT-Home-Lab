# Project 01 – HP EliteBook 840 G6 RAM Upgrade

## Overview

This project documents the successful upgrade of my HP EliteBook 840 G6 laptop from **8GB** to **24GB DDR4 RAM**.

The purpose of this upgrade was to improve system performance and prepare the laptop for future enterprise IT home lab projects including:

- Windows Server 2022
- Active Directory
- Hyper-V
- Group Policy
- Microsoft Intune
- Microsoft Entra ID
- PowerShell

---

# Project Objectives

- Increase installed memory from 8GB to 24GB
- Improve multitasking performance
- Prepare the laptop for virtualization
- Document the upgrade professionally
- Build an IT portfolio project for recruiters

---

# Device Information

| Component | Specification |
|-----------|---------------|
| Laptop | HP EliteBook 840 G6 |
| Processor | Intel Core i5-8365U |
| Operating System | Windows 11 Pro |
| Original RAM | 8GB DDR4 |
| New RAM Installed | 16GB DDR4 |
| Total RAM | 24GB DDR4 |

---

# Tools Used

- Windows 11 Pro
- Task Manager
- System Information (msinfo32)
- Windows Settings
- OBS Studio
- Microsoft Clipchamp
- GitHub

---

# Upgrade Process

1. Documented the existing system configuration.
2. Recorded CPU, memory and system information.
3. Shut down the laptop.
4. Installed an additional 16GB DDR4 memory module.
5. Restarted Windows.
6. Verified that Windows recognised 24GB RAM.
7. Documented the completed upgrade.

---

# Before vs After

| Item | Before | After |
|------|--------|-------|
| Installed RAM | 8GB | 24GB |
| Memory Slots Used | 1 of 2 | 2 of 2 |
| Windows Status | Operational | Operational |
| Virtual Machine Capacity | Limited | Significantly Improved |

---

# Verification

The upgrade was successfully verified using:

- Windows Task Manager
- Windows System Information
- Windows Settings

Windows successfully recognised **24GB** of installed memory after the upgrade.
